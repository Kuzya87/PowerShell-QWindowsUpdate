# PowerShell-модуль "PowerShell-QWindowsUpdate"

## Описание

Модуль PowerShell, предоставляющий функционал для управления обновлениями в Windows 11 24H2 (и выше) и в Windows Server 2022/2025.

## Общие требования

- Код должен выполняться в стандартном встроенном Windows PowerShell в Windows 11 24H2 (и выше) и в Windows Server 2022/2025.
При этом он также должен без проблем выполняться при запуске из сессии PowerShell 7 на вышеупомянутых ОС.

- Блоки справки и комментариев должны быть на русском языке.

- Для файлов, содержащих нелатинские символы, нужна кодировка UTF8 BOM.

- Центральным элементом должен быть класс [QWindowsUpdate], а прикладные функции должны быть лишь обёртками над ним и над вспомогательными функциями (если таковые есть).

- Предполагается только локальное выполнение кода на том компьютере, где производится запуск.

- Передача объектов [QWindowsUpdate] между удалённой PSSession и локальным сеансом не предполагается.

- Нужно, чтобы при запуске в удалённой сессии PSSession код успешно работал.
Предполагается, что в таком случае модуль уже будет присутствовать в этой удалённой сессии.

- Для методов или функций, которые для своей работы потребуют права администратора, должны быть понятные сообщения в случае запуска без этих прав, причём проверка должна быть ещё до выполнения основного кода.
В каких именно методах и функциях - на усмотрение реализации.

- Реализация (класс и функции) не должна опираться на сторонние модули типа PSWindowsUpdate.
На чистом компьютере ничего не должно дополнительно требоваться.

- Тип всех переменных при их объявлении так или иначе должен быть очевиден и однозначен.
Не должно быть неоднозначностей с типами.

- Для командлетов и функций PowerShell (вызываемых в форме `Verb-Noun -Parameter Value`) всегда должны быть явно прописаны названия параметров.
Пример 1: не `Get-Item C:\myfile.txt`, а `Get-Item -Path C:\myfile.txt`
Пример 2: не `Where-Object {$array.Count -eq 4}`, а `Where-Object -FilterScript {$array.Count -eq 4}`

- Везде, где явно не сказано иное, в случае возникновения ошибки возвращать исключение и прекращать работу.

## Требования к модулю PowerShell

- Название модуля - "PowerShell-QWindowsUpdate".

- Корневой модуль - "Root.psm1".

- Версия модуля - семантическое версионирование начиная с "0.0.1".

- Автор - Юрий Кузьмин.

- URL проекта - "https://github.com/Kuzya87/<название модуля>".

- В корневом модуле не должно быть бизнес-логики, там должна быть только подготовительная логика для работы модуля:

    - импортирование классов, функций, скриптов;
    - регистрация типов (блоки type accelerator и так далее);
    - задание общих переменных (переменные окружения и так далее);
    - регистрация алиасов.

- Должны быть подкаталоги "classes" для классов и "functions" для функций.
Каждый класс и функция должны быть в отдельном файле по имени класса или функции.

## Общие требования к классам

- Код классов должен быть в достаточной мере насыщен verbose-сообщениями для удобной диагностики проблем.

## Требования к классу **[QWindowsUpdate]**

- Свойства:

    - **KBArticleIDs** [string[]] - может быть от 0 до нескольких элементов
    - **Title** [string]
    - **Description** [string]
    - **SupportUrl** [string]
    - **UpdateID** [guid]
    - **Categories** [string[]] - может быть от 0 до нескольких элементов
    - **MsrcSeverity** [string]
    - **SizeMb** [double] - размер в мегабайтах (округление до сотых): MaxDownloadSize, а если не заполнено - MinDownloadSize
    - **Downloaded** [bool] - загружено ли, статус на момент поиска обновлений
    - **RebootRequired** [bool] - вероятная необходимость перезагрузки из описания обновления

- Статический метод **StartScan()** для поиска всех доступных обновлений:

    - метод должно быть можно использовать командой типа `$Updates = [QWindowsUpdate]::StartScan()`, где $Updates в результате будет массивом объектов [QWindowsUpdate[]];
    - метод должен возвращать в конвейер массив объектов обновлений [QWindowsUpdate[]];
    - если доступных обновлений не найдено, то ничего не возвращать;
    - информационный выхлоп не нужен.

- Метод **Install()** для загрузки и установки обновления:

    - метод должно быть можно использовать командой типа `$Updates[2].Install()`;
    - метод должен возвращать в конвейер [bool] о необходимости перезагрузки, основываясь на реальной проверке состояния системы после установки;
    - желателен вывод строки прогресса установки обновления, если это можно реализовать без значительного усложения кода;
    - информационный выхлоп не нужен.

- Должен быть метод **Download(string Path)** для скачивания обновления в локальный каталог "Path":

    - метод должно быть можно использовать командой типа `$Updates[2].Download("C:\Download")`;
    - если каталога "Path" не существует, то возвращать исключение с понятным описанием;
    - способ скачивания файла в каталог "Path" - стандартный WUA API и последующий перенос файла;
    - в качестве конечного имени файла использовать оригинальное имя скачиваемого файла;
    - если конечный файл уже существует, то перезаписывать его;
    - метод в конце работы ничего не должен возвращать в конвейер;
    - желателен вывод строки прогресса скачивания обновления, если это можно реализовать без значительного усложения кода;
    - информационный выхлоп не нужен.

- Стандартный метод **ToString()** должен возвращать свойство "Title", а не название класса.

- Должен быть прямой доступ пользователя к классу в обычной сессии PowerShell, чтобы пользователь мог открыть PowerShell и там сразу были доступны класс и функции.

## Общие требования к функциям

- При любых вариантах и параметрах вызова функций должны выполняться условия:

    - вывод timestamp момента начала работы в виде информационного сообщения в консоль (не в конвейер) в формате текущего региона пользователя, цвет Blue;
    - в конце работы вывод количества затраченного времени в виде информационного сообщения в консоль (не в конвейер), цвет Blue, в формате "ЧЧ:мм:сс".

## Требования к функции **Get-QWindowsUpdate**

Это функция для read-only операций получения той или иной информации о доступных обновлениях.

- При вызове без параметров должно происходить:

    - поиск всех доступных обновлений, в результате которого в конвейер должен возвращаться массив объектов `[QWindowsUpdate[]]`.

    То есть это способ для получения объектов обновлений, доступных для установки.

- Должен быть параметр [switch] **Info**, при котором должно происходить:

    - поиск обновлений (без возврата массива объектов [QWindowsUpdate[]] в конвейер);
    - удобная для человека сводка в виде таблицы по результату поиска обновлений в виде информационных сообщений в консоль (не в конвейер), где:

        - в первом более узком столбце свойство "KBArticleIDs" (если несколько, то через запятую);
        - во втором более широком столбце свойство "Title";
        - таблица должна влезать в стандартную консоль PowerShell;
        - таблица должна иметь соответствующие заголовки;
        - под таблицей должна быть информация о необходимости перезагрузки при условии установки всех найденных обновлений;

    - если обновления не найдены, то вместо таблицы просто вывести сообщение об этом.

    То есть это способ для получения пользователем информации о доступных обновлениях.
    Ничего не должно возвращаться в конвейер, только информационные сообщения в консоль.

## Требования к функции **Install-QWindowsUpdate**

Это функция для операций установки обновлений тем или иным способом.

- Вызов без параметров не должен быть возможен.

- Должен быть параметр [switch] **AllAvailable**, при котором должно происходить:

    - поиск всех доступных обновлений;
    - установка всех найденных обновлений, в конце работы которой в конвейер должен возвращаться один объект [bool] об общей результирующей необходимости перезагрузки.

    То есть это быстрый способ для поиска и установки всех доступных обновлений.

- Должен быть параметр **Update**, принимающий на вход один или несколько объектов обновлений [QWindowsUpdate], при котором должно происходить:

    - установка обновлений, переданных из параметра "Update", в конце работы которой в конвейер должен возвращаться один объект [bool] об общей результирующей необходимости перезагрузки.

    Должна быть возможность передавать объекты обновлений [QWindowsUpdate] по конвейеру командой типа `$Updates | Install-QWindowsUpdate`.

- Параметры "AllAvailable" и "Update" должны быть взаимоисключающими.
